# Веб-приложение сегментации заболоченных пространств

## Описание репозитория

Этот репозиторий содержит веб-приложение для классификации водно-болотных угодий, разработанное для работы в Google Colab. Проект включает следующие компоненты:

### Основные файлы:
- `web_wetlands.ipynb` - Jupyter Notebook с полным кодом приложения
- `app.py` - основной скрипт Flask-приложения
- `template.py` - генератор HTML-шаблонов
- `path.py` - обработчик путей к файлам
- `lib_install.txt` - список требуемых библиотек

### Модель и данные:
- Предобученная модель: `WD_6classes_25epochs_RESNET152_batch4.hdf5`
- База данных пользователей: `login_db.sqlite`

### Документация:
- Инструкция по запуску (в данном README)
- Подробное описание работы приложения: `описание.docx`

## Требования
- Google Colab с доступом к GPU
- Google Drive для хранения модели и БД
- Учетные данные для доступа (см. таблицу ниже)

## Как использовать
Приложение доступно для запуска непосредственно в Google Colab по [ссылке](https://colab.research.google.com/drive/1k9MnpFTO64EXBXdESy8ikTA0kP0361BN?usp=sharing).

Для локального запуска используйте файл `web_wetlands.ipynb`, следуя инструкциям в ноутбуке.
